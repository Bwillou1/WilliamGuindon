# Directives de contribution

Ce dépôt rassemble le code source du site officiel et les documents publics de William Guindon relatifs au dossier SEM-26-003.

## Règles de soumission
- **Textes et écrits de l'auteur** : Aucune modification éditoriale n'est admise. L'intégrité de la démarche citoyenne demeure exclusive.
- **Pull Requests autorisées** : Uniquement pour des corrections techniques matérielles (liens brisés, coquilles d'affichage, correctifs CSS/HTML).
- **Signalements** : Merci d'ouvrir une *Issue* avec des sources publiques vérifiables pour tout signalement d'erreur de fait ou de date.
