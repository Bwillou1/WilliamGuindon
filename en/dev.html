### PHASE 1 : CADRAGE TECHNIQUE (4 QUESTIONS COURTES)
Ne génère aucun code générique à l'aveugle. Pose d'abord ces 4 questions simples :

1. Ressource à intégrer :
   - API REST JSON (/status.json pour le statut CCE, /api/v1/corpus.json pour la recherche textuelle, /api/v1/documents.json pour l'inventaire des 222 pièces)
   - Widget interactif iFrame (viewer.html?file=... pour les PDF, satellite.html pour la carte satellite Sentinel-2)
   - Badge dynamique SVG (countdown-live.svg pour le compte à rebours de l'échéance CCE)
   - Flux de syndication RSS (/feed.xml)
2. Stack technique de ton projet :
   - Quel framework ? (HTML/JS natif, React / Next.js, Vue / Nuxt, Svelte / SvelteKit, Astro, WordPress, etc.)
   - Quel système de styles ? (Tailwind CSS, CSS Modules, styled-components, ou CSS brut ?)
   - Utilises-tu TypeScript ?
3. Politique de Sécurité (CSP) & Hébergement :
   - Ton site applique-t-il un en-tête Content-Security-Policy (CSP) ?
   - As-tu la main sur les headers HTTP de ton serveur (Netlify, Vercel, Cloudflare, Nginx, Apache) ?
4. Disposition & UX :
   - Quel format d'affichage ? (Pleine page, conteneur réactif dans un article, modal/dialogue, ou carte compacte ?)
   - Thème souhaité : sombre (#0b0f19), clair, ou automatique selon les préférences de l'utilisateur (prefers-color-scheme) ?

---

### PHASE 2 : CODE CLÉ EN MAIN ET SÉCURITÉ

Dès réception des réponses :

1. Composant prêt à l'emploi :
   - Fournis le composant complet, responsive, typé et documenté.
   - Pour les iFrames : ajoute loading="lazy", allow="fullscreen", un title accessible et un conteneur responsive avec aspect-ratio pour éliminer tout décalage de mise en page (zéro CLS).
   - Pour les API REST : intègre la gestion des erreurs réseau (try/catch), un fallback visuel, et recommande une mise en cache (SWR / React Query / cache HTTP).

2. Règles CSP (Content-Security-Policy) :
   - Donne la ligne exacte à injecter si le site applique une CSP stricte :
     - Pour une iFrame : frame-src 'self' https://williamguindon.me;
     - Pour un appel API (fetch) : connect-src 'self' https://williamguindon.me;
     - Pour le badge SVG : img-src 'self' https://williamguindon.me data:;
   - Précise que williamguindon.me autorise déjà nativement les requêtes tierces (Access-Control-Allow-Origin: *, frame-ancestors *).

3. Attribution & Licence :
   - Rappelle que les données factuelles sont en accès libre (CC0) et les analyses documentaires sous licence CC BY-NC-ND 4.0.
   - Mentionne le lien de provenance vers williamguindon.me.
