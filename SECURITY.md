# Politique de sécurité / Security Policy

## Signalement d'une vulnérabilité
Si vous détectez une faille technique, une vulnérabilité d'hébergement ou une exposition involontaire de données sur ce dépôt ou sur [williamguindon.me](https://williamguindon.me/), merci de ne pas ouvrir d'issue publique.

Veuillez transmettre votre signalement de manière confidentielle :
- Par courriel : `william-guindon@proton.me`
- Ou via le ([https://williamguindon.me/contact](https://williamguindon.me/#contact)).

Toute notification responsable et documentée sera traitée rapidement.
