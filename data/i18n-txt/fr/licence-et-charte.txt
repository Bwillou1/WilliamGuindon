#### Recommandations Techniques de Formats :
• SVG (Vectoriel) : Format recommandé par excellence pour le Web et la presse papier (netteté
infinie, poids ultra-léger < 3 Ko). • WebP : Format matriciel optimisé de référence pour les
applications modernes et les prévisualisations (70% plus compact que le PNG avec transparence alpha
intégrale). • JPEG XL (.jxl) : Format nouvelle génération de haute fidélité d'archivage. Note : JPEG
XL n'est pas encore activé par défaut dans tous les navigateurs commerciaux, mais demeure disponible
sur demande pour les archives graphiques.
