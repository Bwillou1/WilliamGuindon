# Code de conduite et politique de contribution

Ce dépôt héberge le code source du site officiel et les pièces documentaires publiques de William Guindon (notamment relatives au dossier CCE SEM-26-003).

## 1. Intégrité des textes et documents
- Les textes, prises de position, analyses et mémoires juridiques publiés ici sont placés sous licence [Creative Commons CC BY-NC-ND 4.0](https://creativecommons.org/licenses/by-nc-nd/4.0/).
- **Aucune contribution modifiant le fond, les opinions ou les écrits de l'auteur n'est acceptée.** L'intégrité de la démarche citoyenne et de la parole de l'auteur demeure exclusive. Toute Pull Request visant à altérer le sens ou le contenu d'un texte sera immédiatement fermée sans suite.

## 2. Signalements et contributions autorisés
Les interactions extérieures via Issues ou Pull Requests se limitent strictement à :
- **Problèmes techniques & affichage** : signalement de liens brisés, fautes de frappe matérielles, bogues CSS ou erreurs de rendu du site.
- **Ressources documentaires publiques** : transmission de pièces officielles publiques et vérifiables permettant de documenter la chronologie ou de rectifier une donnée matérielle chiffrée.

## 3. Comportement attendu
Toute communication dans les Issues, Pull Requests ou échanges doit rester courtoise, factuelle et respectueuse. Les insultes, attaques personnelles, campagnes de dénigrement ou tentatives d'intimidation entraîneront un blocage immédiat et la fermeture des fils de discussion.
